# LLM 리포트 경진대회 설계 기록

사내 LLM으로 본인 업무를 분석하고 답안을 만드는 경진대회의 **출제 설계 기록**이다. AI 기초 학습 교재나 현재 운영 공지가 아니다. 90분 초안에서 50분 설계로 바뀌는 과정과 평가 목적의 차이를 따라 읽는다.

## 읽기 순서

1. [검토 안내](./review-notes.md): 버전 차이, 기술적 적용 조건, 현재 미확인을 먼저 확인한다.
2. [설계 문맥](./CONTEXT_CODEX.md): 45분 작성·5분 제출, 3파트와 핵심 프롬프트 2~3개를 제안한 별도 설계 문맥이다.
3. [전환 중 설계서](./contest-spec.md): 2026-05-20 v0.2이지만 같은 위치의 답안지는 여전히 90분 초안이다.
4. [50분 개정 자료 목차](./v2-50min/README.md): 개정 설계서·양식·두 채점 예시를 비교한다.
5. [정리 기록](./organization-log.md): 검토 범위와 보류 결정.

## 90분 초안과 입력 자료

| 자료 | 용도 |
|---|---|
| [입력 메모](./bgk.txt) | 당시 요구사항 원문. 첨부 텍스트를 수정하지 않았다. |
| [90분 답안지](./exam-paper.md) | 3영역·균등 20점 기준의 과거 양식. 50분 제출 양식으로 사용하지 않는다. |
| [90분 모범 예시](./sample-model-answer.md) | 가상의 수치·사례로 구성한 상한 캘리브레이션 사례. |
| [90분 LLM-only 예시](./sample-llm-only-answer.md) | 의도적으로 약하게 작성한 하한 비교 사례. 실제 참가자의 부정행위를 입증하지 않는다. |

동일 이름의 문서를 합치지 않았다. 작성 시간·배점·평가 목적이 달라 버전 비교에 필요한 내용이다. **최종 승인된 운영안은 이 저장소만으로 확인되지 않는다.**
