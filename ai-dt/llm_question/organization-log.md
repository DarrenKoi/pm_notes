HERDR_ENV=1을 확인하고 `herdr pane current --current`를 재시도했으나 `pane_not_found`였다. 작업 전용 Claude pane에 연결하지 못했으며 다른 프로젝트 pane을 제어하지 않았다. Claude 의견은 받지 못했다. 버전 통합·평가 타당성·공유 규정·최종 승인안 선택은 협의가 필요한 결정으로 보류했다. 원문 보존, 날짜·용도 표시, 실제 경로 복구와 공식 모델 역할 구분은 진행했다.

## 근거와 미확인

출제 버전의 근거는 각 원문의 2026-05-15/20 표기와 서로 다른 문항·배점이다. 변동 기술의 공식 출처·확인 범위는 검토 안내에 기록했다. 사내 LLM 연결·실제 모델 revision·검색 인덱스·방화벽·45분 완주·공동 채점·현재 승인·회사 공유 규정은 미확인이다. 코드·모델 다운로드·API·실제 대회를 실행하지 않았다.

## 검증

1. **목록·내용 보존**: 원래 Markdown 9개 전부 개별 결과를 기록했다. 첫 제목 뒤 원문 전체가 동일함을 대조했고 v2 입력 메모 링크 1건만 허용 차이로 확인했다. 원래 절 160개와 예시·표·채점 문맥을 유지했다. 첨부 텍스트·HTML 2개 SHA256은 초기 값과 같다.
2. **근거·로컬 확인**: 공식 모델 카드 3건으로 생성/검색 모델과 BGE-M3 텍스트 역할을 구분했다. 두 배점 체계의 100점 합계, 네 샘플의 상하한 합산을 로컬 Python으로 검산했다. 사내 서비스·GPU·실제 대화·채점 실행은 검증하지 않았다.
3. **참조·앱 확인**: 현재 Markdown 13개의 YAML 확인일과 상대 링크·앵커·첨부 검사에서 새 오류와 남은 오류 모두 0개다. Obsidian CLI에서 13개 properties를 확인했고 정확한 pm_notes vault에서 README → review-notes 읽기 이동, 버전 비교 표와 기술 조건·출처 표 렌더링을 확인했다. 모든 문서의 모든 화면을 개별 시각 검사한 것은 아니다. `git diff --check` 통과.

수정은 해당 주제의 Markdown과 ai-dt 진행 기록에만 한정했다. 미확인·협의 보류가 있어 기술/운영 전체 인증 상태는 partial이다.
