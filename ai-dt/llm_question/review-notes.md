# 출제 기록 검토 안내

## 목적과 사용 방법

이 자료의 목적은 참가자가 LLM 결과를 자기 업무 맥락에 적용하고 검증하는 과정을 평가할 문항을 설계하는 것이다. Workflow를 분해하고, 회수할 자료와 사람이 판단할 지점을 구분한 뒤, 최종 답안에 반영·교정한 내용을 기록하는 구조다. 실제 대회를 다시 운영하려면 승인된 시간·문항·배점·도구·공유 범위를 하나의 운영 공지에서 확정해야 한다. 이 검토는 운영 규칙을 새로 승인하지 않는다.

## 서로 다른 설계는 합치지 않는다

| 기록 | 작성 조건 | 의미와 남은 차이 |
|---|---|---|
| 루트 답안지·샘플 | 90분, 3영역, 5축 각 20점 | 2026-05-15 초안 기준. 루트 설계서의 v0.2와 불일치한다. |
| 루트 설계서 | 50분, 2영역, 비대칭 배점 | 2026-05-20 전환 기록. 시간 배분에 고과 찬반이 남지만 본문 영역2는 오답 검증이다. |
| v2-50min | 50분, 2영역, 비대칭 배점 | 추가 결정에서 반복업무 1개를 채택했다. 모범 샘플은 여러 업무 유형을 나열하고 새 양식의 3구분·메타 두 필드와 완전히 일치하지 않는다. 재사용 시 별도 갱신 필요. |
| CONTEXT_CODEX | 45분 작성+5분 제출, 3파트 | 생산적 리포트 작성 중심의 다른 설계 문맥. 2영역안과 동일 확정안으로 취급하지 않는다. |

`codex/`와 `CONTEXT.md`라는 원문 언급은 현재 이 폴더에서 대상 자료를 찾을 수 없어 미확인이다. 없는 문서를 새로 추정해 만들거나 다른 주제의 문서를 연결하지 않았다. v2 설계서의 `bgk.txt` 상대 링크만 실제 위치에 맞게 복구했다.

## 기술적 적용 조건 — 2026-10-04 확인

**Qwen3-VL이라는 계열명만으로 검색용 이미지 임베딩을 얻는다고 가정하지 않는다.** 공식 `Qwen3-VL-8B-Instruct`는 이미지·텍스트 입력에서 텍스트를 생성하는 모델이고, 별도의 `Qwen3-VL-Embedding-8B`는 텍스트·이미지 등을 검색용 벡터로 표현하는 모델이다. 원문 모범 예시의 “Qwen3-VL 이미지 임베딩 → BGE-M3 카드 회수”는 구현이 확인된 파이프라인이 아니다. BGE-M3는 텍스트 검색용 임베딩 모델이다. 서로 다른 모델의 벡터는 차원이 같아도 공통 공간이라고 보장하지 않는다.

실제 적용에는 다음 중 하나의 설계와 평가가 필요하다. 이미지에서 텍스트 설명을 생성한 뒤 그 설명과 텍스트 카드를 **같은** 텍스트 임베딩 모델로 처리하거나, 질의·카드에 호환되는 멀티모달 임베딩 모델을 사용한다. 설명 생성에는 정보 손실·환각이 있을 수 있고, 모델별 입력 처리·revision·차원·유사도 척도를 고정해야 한다. 이 대회의 SEM 이미지나 사내 검색 품질은 검증하지 않았다.

| 일차 자료 | 확인한 범위 | 확인일 |
|---|---|---|
| [Qwen3-VL-8B-Instruct 공식 모델 카드](https://huggingface.co/Qwen/Qwen3-VL-8B-Instruct) | 생성 모델의 역할. 특정 사내 분류 품질의 근거가 아님. | 2026-10-04 |
| [Qwen3-VL-Embedding-8B 공식 모델 카드](https://huggingface.co/Qwen/Qwen3-VL-Embedding-8B) | 별도 멀티모달 검색 모델과 통합 표현 공간. | 2026-10-04 |
| [BGE-M3 공식 모델 카드](https://huggingface.co/BAAI/bge-m3) | 텍스트 기반 다국어·다기능 검색 모델. | 2026-10-04 |

위 자료는 확인일의 모델 카드이며 다운로드 revision을 고정한 실행 검증은 아니다. 과거 원문의 모델 가용성·회사 인프라·방화벽·색인 내용은 업무 당시 조건으로 남기고 현재 사실로 인증하지 않는다.

## 평가 문구를 읽는 조건

- “오답 인용은 위조 불가능”은 입증되지 않은 설계 가정이다. 작성된 인용문·교정 흔적만으로 실제 대화나 작성 주체를 입증할 수 없다. 원문의 “LLM-only 판정”은 당시 채점 제안이며 일반적인 탐지법이 아니다.
- 약한 답안의 정성적 표현과 강한 답안의 구체적 수치는 캘리브레이션 예시다. 자세한 숫자나 장비명이 있다는 것만으로 사실의 정확성·검증 능력이 증명되지 않는다. “사실 진위 대신 형식을 채점”하는 v2 제안과 “검증 능력 평가” 목적 사이의 정합성은 보류했다.
- 오답을 못 찾은 답안을 일괄 미달로 간주하는 규칙, 예시 점수 범위와 실제 순위 변별력은 실행·채점자 간 일치도 자료가 없다. 모범 예시는 실제 LLM 대화 로그가 아니라 가상의 재구성이다.
- 내부 공유만으로 익명화·동의·기밀 처리 조건이 자동 면제되지는 않는다. 당시 문구는 과거 운영 의견이다. 현재 회사 공유 규정과 승인 여부는 미확인이며 이 정리에서 법적 판단을 내리지 않았다.

각 초안의 배점 합계는 100점이다. 샘플 하한·상한 합산은 90분 모범 84~94, 비교 31~44; 50분 모범 83~93, 비교 22~35로 원문과 일치한다. 이는 산술 확인이며 평가 타당성 증명이 아니다.
