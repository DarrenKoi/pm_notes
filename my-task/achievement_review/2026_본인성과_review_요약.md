# 2026년 본인 성과 Review — 1페이지 요약 (공개용)

> 상세본: [2026_본인성과_review.md](./2026_본인성과_review.md) · 사내 시스템·조직·행사명은 일반 명칭, 수치는 상대값으로 적었다.

---

**[요약]**
AI/DT 확산 담당으로, 직접 만든 두 솔루션이 회사의 공식 포상을 받았고 타 조직 TF의 업무 기반이 되었다. 백업 인력 없이 고유 과제 3건과 지원 업무를 개발·운영·기획까지 끝까지 맡았다.

**1. 정렬 실패 대응 Agent — 사내 AI 행사 AX 혁신 공모전 수상**
- 센터 One Stop 체계의 핵심인 레시피 자동 생성 파이프라인의 첫 PoC. 이미지 처리·VLM 자동화·레시피 튜닝을 한 과제에서 함께 검증했다.
- PoC 결과: CV 정렬 성공률 약 25%p 향상(저배율), 클릭 성공률 99% 수준, 기준 표식 없이 찾는 Search Around 개발
- 배포 시 기대효과: 전체 측정의 약 10%를 차지하는 정렬 실패의 건당 처리 시간 80% 단축

**2. 계측 장비 관리·분석 플랫폼 — 현업이 매일 쓰는 데이터 기반**
- v3 전면 재구축: 코드 약 40배, 대상 장비 약 1.5배, 사내 실데이터 연결
- 대표 사례 — 계측 효율화 TF: 장비 측정 대기 시간이 크게 늘어 R&D가 지연되고 있다. 대기 시간을 약 1/4로 줄이려면 장비를 추가로 사야 하지만, 효율화로 먼저 줄이고 부족분만 구매하기로 합의했다. 이 중 계측 포인트 간소화는 이 플랫폼이 필수이며, 추가 구매 필요 장비의 약 29% 확보를 목표로 10월 현재 약 10%를 확보한 것으로 추정한다.
- 그 밖의 기능: 디바이스 통계, 통합 분석 대시보드, 장비 간 편차 분석, 실시간 알람, RAG 어시스턴트. 데이터를 묻고 기다리는 소통을 없애 엔지니어가 바로 업무를 진행한다.

**3. 동료·타 조직 기여**
- 교대 인력이 실시간 알람·RAG로 담당자 호출 없이 스스로 대응
- 현업 부서와 계측 데이터 뷰어·이미지 분석 툴 공동 개발, 레시피 자동 생성 기술 교류
- 부서 간 AI 협의체 조율, 부문 공용 AI Agent 리뷰 양식·과제발굴 템플릿 제작
- AI/DT 교육 커리큘럼 Expert 분과 담당: 커리큘럼과 인증 체계 설계

**4. 보완할 점과 2027 조치**
- 정렬 실패 대응 Agent 현업 투입과 플랫폼 오픈이 계획보다 늦어졌다. 정확도 검증이 남은 점과 1인 개발·운영 병행이 원인이다. → 단일 장비 시범 후 확대, 팀 단위 운영 체계로 전환
- 요청이 개인에게 몰리고 노하우가 개인에게 쌓여 있다. → 요청 창구 일원화, 에이전트 개발 방식을 가이드·교류회로 팀에 전파
- 개발과 병행하느라 기획 학습이 부족했다. → 2027년 신규 AI 과제 기획 1건 이상 리드

**5. 승격 추천 사유**
- 성과를 회사가 공식 인정했다(AX 혁신 공모전 수상). 이 과제는 센터 중점 과제의 기술 가능성을 증명했다.
- 내가 만든 플랫폼이 장비 구매를 줄이는 타 조직 TF의 필수 기반이 되었다.
- 개발을 넘어 기획(실행기획 11단계 완주), 교육·인증 설계, 부서 간 조율 등 상위 레벨의 일을 이미 하고 있다.

**6. 2027 계획**
- 신규 AI 과제 기획 리드, 에이전트 개발 방식 팀 전파
- 정렬 실패 대응 Agent 확대, 플랫폼 확장(장비군 연계 + 분석 AI Agent), 장비 데이터 매핑 Agent
