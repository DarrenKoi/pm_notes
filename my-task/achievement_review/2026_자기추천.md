# 2026년 승격 자기 추천서 (공개용)

> 성과 리뷰 요약과 별도로 시스템에 올리는 문서다. 내용이 일부 겹쳐도 이 문서만 읽고 추천 사유를 판단할 수 있게 썼다. 사내 시스템·조직명은 일반 명칭, 수치는 상대값으로 적었다.

---

**[추천 요지]**
AI/DT 확산 담당으로, 2026년 End-to-End로 개발한 두 솔루션이 모두 사내 공식 포상을 받았다. 그중 계측 플랫폼은 현업이 매일 쓰는 운영 시스템이 되었고, 타 조직 TF가 장비 추가 구매를 줄이는 데 필수 기반이 되었다. 개발 외에 과제 기획, 교육·인증 체계 설계, 부서 간 협의 조율까지 수행하며 이미 상위 레벨의 역할을 하고 있다. 승격 후에는 이 역할을 팀·부문 단위로 넓히겠다.

**1. 성과가 사내 공식 포상으로 검증됨 (2년 연속, 2건)**
- 계측 장비 관리·분석 플랫폼 — 기반기술센터 AI/DT Summit 2025 최우수상
- 정렬 실패 대응 Agent — 사내 AI 행사 AX 혁신 공모전 수상
- 정렬 실패 대응 Agent는 센터 One Stop 체계의 핵심인 레시피 자동 생성 파이프라인의 첫 PoC다. 이미지 처리·VLM 자동화·레시피 튜닝을 한 과제에서 검증해 센터 중점 과제의 기술 실현 가능성을 입증했다. 배포 시 전체 측정의 약 10%를 차지하는 정렬 실패의 건당 처리 시간이 80% 줄어든다(목표값).

**2. 개발 산출물이 타 조직의 업무 기반으로 자리잡음**
- 계측 효율화 TF: 장비 측정 대기 시간이 크게 늘어 약 1/4로 줄이려면 장비 추가 구매가 필요했다. TF는 효율화로 먼저 줄이고 부족분만 구매하기로 했으며, 그중 계측 포인트 간소화는 이 플랫폼의 디바이스 통계 없이는 수행할 수 없다. 추가 구매 필요 장비의 약 29% 확보가 목표이고, 10월 현재 그중 약 1/3(필요 장비의 약 10%)을 확보한 것으로 추정한다.
- 현업이 매일 사용한다. 교대 인력은 실시간 알람과 RAG 어시스턴트로 담당자 호출 없이 직접 대응한다. 개인 과제를 넘어 부문 운영 인프라로 자리잡았다.

**3. End-to-End 개발·운영 역량 입증**
- 요구사항 정의 → 설계 → 개발 → 배포 → 운영 → 사용자 대응까지 전 과정을 직접 수행했다. 백업 인력 없이 고유 과제 3건과 지원 업무를 병행했다.
- 플랫폼 v3를 전면 재구축했다: 코드 약 5천 줄 → 약 25만 줄(약 50배), 대상 장비 약 1.5배, 사내 실데이터 연동. 디바이스 통계·실시간 알람·RAG 어시스턴트 등을 신규 개발했다.
- 전문 개발 조직 없이 AI 코딩 도구와 하네스 설계(Harness Engineering) 방식으로 엔터프라이즈급 시스템을 구축·운영하는 방법을 체득했고, 이를 팀에 전파할 수 있는 형태로 정리하고 있다.

**4. 상위 직급에 요구되는 역할 선행 수행 — 과제 기획·인력 육성·조직 간 조율**
- 과제 기획: 정렬 실패 대응 Agent의 실행기획 11단계 전 과정을 개발 담당자가 직접 수행해, 부문 AI 과제 기획의 기준 사례(Reference Case)를 확립했다. 2027 부문 공통 기반 과제(장비 데이터 매핑 Agent)를 발굴·제안했다.
- 인력 육성 체계 설계: AI/DT 교육 커리큘럼 Expert 분과를 맡아 2개 과정(96h·24h)과 인증 체계를 설계했다.
- 조직 간 협업·표준화: 부서 간 AI 협의체를 조율하고, 현업 부서와 계측 데이터 뷰어·이미지 분석 툴을 공동 개발했다. AI Agent 리뷰 양식과 과제발굴 템플릿을 부문 공용 표준으로 마련했다.

**5. 승격 후 계획**
- 팀 단위 Agent 프로젝트 리드: 지금은 1인이 Agent 1개를 맡아 개발하지만, 앞으로는 자기 개선 루프(Self-improvement Loop)를 갖춘 Agent를 팀 단위로 개발하는 방향으로 바뀌고 있다. 이 전환을 주도해 데이터 생성·적재 → Agent 개발 → 운영·개선까지 End-to-End로 리드한다.
- AX 지식의 현업 전파: AX 조직에서 익힌 Agent 개발·운영 노하우를 가이드 문서와 교류회로 현업 엔지니어에게 전파한다. 개인에게 쌓인 노하우를 팀 자산으로 바꾸고, 요청 창구를 일원화한다.
- 진행 과제 확대: 정렬 실패 대응 Agent 확대, 플랫폼 확장(추가 계측 장비군 연계 + 분석 AI Agent), 2027 장비 데이터 매핑 Agent 추진
