# Auto Recipe Creation TF: 한 장 요약

> 숙련 엔지니어의 레시피 셋업 노하우를 회사 자산으로 남기고, 장비가 늘어도 셋업 인력을 같은 비율로 늘리지 않는 구조를 만들고자 합니다.

## 문제

- MI 장비 레시피 셋업은 숙련 엔지니어가 원격 화면에서 손으로 반복하는 작업임. 레시피당 평균 30~60분 (현업 경험치)
- 판단 기준이 사람에게만 있어 담당자가 바뀌면 노하우가 사라짐
- 장비, 제품이 늘면 셋업 인력도 같은 비율로 늘어야 함. Align Fail 알람이 나면 사람이 올 때까지 장비가 멈춤

## 해결 방향

- 엔지니어 작업 녹화에서 절차와 판단 근거를 추출하고 담당 엔지니어가 승인해, 다른 엔지니어가 찾아 쓰는 **지식 자산**으로 축적함
- AI는 현재 화면에 맞는 승인 절차를 찾아 **한 단계씩** 수행하고, 결과가 불명확하면 멈춤. 위험 조작과 저장, 적용은 엔지니어가 승인함
- 장비마다 따로 만들지 않고 **공통 플랫폼** 하나 위에 장비별 절차만 얹음. 1차 PoC(Align Fail 대응)에서 API 없는 장비 화면을 사내 AI로 읽고 조작할 수 있음을 확인함

## 단계별 타겟

| 시기 | 타겟 | 회사에 남는 것 |
|---|---|---|
| 2027 상반기 | CD-SEM, Thickness Align Fail 무인 대응 | 장비 가동 시간 회수 |
| 2027 연말 | 1차 3개 장비군 셋업 절차, 노하우 지식 자산화 | 노하우의 조직 자산화 |
| 2028 | 엔지니어 앞에서 반복 입력 대행 | 엔지니어 직접 투입 시간 감소 |
| 2029 | AI가 셋업을 진행하고 특이 사항 때만 엔지니어 개입 | 셋업 인력을 장비 수에 비례해 늘리지 않음 |

- 효과는 엔지니어 직접 투입 시간과 예정에 없던 개입 횟수로 확인함. 기준선은 2027-02 실측, 측정 전에는 목표를 숫자로 정하지 않음
- 단계마다 검증 증거를 확인한 뒤에만 다음 단계로 확대함

## 요청 사항

- **ARC TF 구성 승인** (2027-01~12)
- **1차 지정군(CD-SEM, Thickness, VeritySEM) 담당 엔지니어 협업**: 장비군마다 1~2명, 주 5시간
- **개발 인력 2명** (TF 리드 포함, 각 50%, 실질 1명)
- 새 서버 구매 없음. 기존 사내 AI 서버와 서버 자원 사용, 녹화 스토리지는 2027 하반기에 사용량 실측 후 요청
