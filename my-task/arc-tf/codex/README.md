# Video-to-Workflow 발표자료 아카이브

> 제작한 발표자료의 슬라이드 이미지와 텍스트를 함께 보관합니다.

## 왜 필요한가? (Why)

PowerPoint를 열지 않고도 설계 내용을 읽고, 슬라이드별 근거와 JSON 계약을 확인할 수 있도록 정리했습니다.

## 핵심 개념 (What)

- `video-to-workflow-agent.md`: 슬라이드 22장의 본문, 표, JSON 예시와 발표자 노트
- `images/`: 각 슬라이드의 PNG 이미지 22장, 1280 × 720 해상도
- 이미지는 완성된 슬라이드의 렌더링입니다. 별도로 생성한 삽화 파일은 없습니다.

## 어떻게 사용하는가? (How)

[발표자료 전체 텍스트와 이미지](video-to-workflow-agent.md)를 엽니다. Markdown의 이미지 링크는 `images/` 폴더를 상대 경로로 참조하므로, 다른 곳으로 옮길 때는 폴더 전체를 함께 복사합니다.

자료는 제안 설계이며 실장비 검증 결과가 아닙니다. 원본 PPTX는 변경하지 않았습니다.
