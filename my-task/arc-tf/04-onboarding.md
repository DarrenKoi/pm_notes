# 온보딩 학습 과정 (2027-01~02, 8주)

> MI 현업 엔지니어가 AI Agent로 레시피를 자동화할 때 알아야 할 배경 지식을 쌓는 TF 전용 실무 과정.

## 왜 필요한가

셀 엔지니어는 장비와 레시피는 잘 알지만, LLM·VLM이 무엇을 잘하고 무엇을 못하는지는 모른다. 이걸 모르면 두 가지가 생긴다.

- Agent에게 맡기면 안 되는 판단(정밀 좌표, 반복 가능한 판정)을 맡기는 절차를 쓴다.
- Agent가 실패했을 때 원인이 모델인지, 화면 품질인지, 절차 정의인지 구분하지 못한다.

목표는 엔지니어가 **자기 장비의 레시피 절차를 Agent가 실행할 수 있는 형태로 정의하고, 결과를 판정할 수 있게** 되는 것이다. AI 개발자를 만드는 과정이 아니다.

## 전제

- **Python 기초는 다루지 않는다.** 코드를 읽고 간단히 고칠 수 있는 정도의 소양은 갖고 온다.
- 겸직 시간(주 ⟨확인: N⟩시간) 안에서 진행한다. 강의는 짧게 하고 실습을 길게 한다.
- 강사는 리드와 공통 플랫폼 팀이 맡는다.
- 1차·2차 셀 엔지니어가 모두 듣는다.

## 과정

| 주차 | 주제 | 배우는 것 | 실습 |
|---|---|---|---|
| 1 | TF와 플랫폼 개요, Git | ARC 목표, 셀의 역할, 저장소 구조, 브랜치와 리뷰 | 저장소 받기, 문서 수정 PR |
| 2 | LLM·VLM의 특성 | 잘하는 것(화면 의미 이해, 설명), 못하는 것(좌표가 흔들림, 기억 없음, 환각), 프롬프트가 결과를 바꾸는 방식 | 같은 화면을 여러 번 물어보고 답이 흔들리는 것 확인하기 |
| 3 | 왜 VLM과 CV를 나눠 쓰는가 | "어디를 볼지"는 VLM, "정확히 어디인지"는 CV. 이미지 매칭 점수 읽는 법 | PoC의 Align Key 탐색 결과를 보고 점수 해석하기 |
| 4 | 컴퓨터 사용 Agent의 동작 | 화면 캡처 → 판단 → 조작 → 검증 순환, 실패 유형(화면 품질, 모델, 절차) | 플랫폼으로 비생산 화면에서 클릭·입력 시켜 보기 |
| 5 | 안전 규칙과 승인 | 검증 실패 시 중단, 되돌릴 수 없는 조작, 저장 전 승인, 증거 기록 | 실패 기록을 보고 원인 분류하기 |
| 6 | 작업 녹화 → 절차서 | 화면 녹화, 조작 타임라인, 한국어 절차서로 바꾸기 | 자기 장비 레시피 셋업 1건 녹화하고 절차서 만들기 |
| 7 | 절차를 플랫폼에 정의하기 | 단계, 각 단계의 성공 조건, 실패 시 행동, 조작별 승인 분류 | 6주차 절차서를 절차 정의로 옮기고, 녹화본에 대고 모의 실행하기 |
| 8 | 기준선 측정과 판정 기준 | 측정 양식으로 현재 셋업 시간 재기, 성공 판정 기준 정하기 | 셀별 기준선과 대표 레시피 유형을 발표 |

레시피 셋업 기능은 3~6월에 만든다. 그래서 온보딩 실습은 **녹화본과 모의 실행**으로 하고, 실제 장비 실행은 1차 구축 단계에서 한다.

## 기준선 측정 양식

8주차에 셀마다 이 양식으로 잰다. 파일럿에서도 같은 양식을 쓴다.

| 항목 | 적는 것 |
|---|---|
| 레시피 유형 | 셀의 대표 유형 1개 |
| 구간 | 자동화 대상 구간(측정 위치·Align 셋업)의 시작 화면과 끝 화면 |
| 소요 시간 | 구간 안의 실패·재작업·수동 인계를 포함한 시간. 승인 대기는 따로 |
| 예정에 없던 개입 | 반드시 거치는 승인은 빼고 센다 |
| 첫 측정 결과 | 셋업 뒤 첫 측정의 성공/실패 |
| 표본 수 | ⟨확인: 유형당 최소 건수⟩ |

8주차 발표 결과가 [TF 구성 기획안](./01-tf-proposal.md)의 ⟨확인⟩ 칸(현재 셋업 시간, 목표 단축률)을 채운다.

## 수료 기준

- 자기 장비 레시피 셋업 1건의 절차서가 있다.
- 그 절차를 플랫폼 절차로 정의하고, 녹화본에 대고 모의 실행해 봤다.
- Agent 실패 기록을 보고 원인(화면 품질 / 모델 / 절차 정의)을 구분할 수 있다.
- 셀의 기준선과 성공 판정 기준이 정해져 있다.

## 선택 과정

더 깊이 알고 싶은 엔지니어는 [AI/DT 교육 커리큘럼](../ai-dt-curriculum/README.md)에서 준비 중인 오픈웨이트 LLM 심화 과정을 추가로 들을 수 있다. TF 수료와는 관계없다.

## 준비물

- ⟨확인: 실습용 PC와 셀별 작업 녹화본 (6주차 전 녹화 승인 필요)⟩
- ⟨확인: 실습 중 VLM 호출 한도⟩
- 실습 자료: PoC의 공개 가능한 화면 예시와 실패 기록
