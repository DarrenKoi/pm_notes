# 2029년 "한 장비군 완성"의 정의와 그 장비군

## Question

2029년까지 목표로 하는 **"최소 한 장비군 완성"** 은 어떤 상태인가? 그리고 그 장비군은 어디인가?

정할 것:
- 완성의 뜻: 그 장비군의 레시피 유형 전부인가, 대표 유형 몇 개인가. Agent가 셋업을 끝까지 진행하고 엔지니어는 특이 사항·위험 때만 개입하는 비율이 얼마면 완성인가
- 완성 장비군 후보: CD-SEM(리드 담당, 로컬 RCS 경로, PoC 자산이 가장 많음) 또는 다른 장비군
- 나머지 장비군은 2029년에 어느 단계까지 가 있어야 하는가 (2030 회사 목표와의 연결)

## Resolution

2026-11-06 grilling에서 정함.

**완성 장비군: CD-SEM과 Thickness 두 개**
- CD-SEM: 리드 직접 담당, 로컬 RCS 경로, PoC 자산이 가장 많고 2027 Align Fail도 여기서 운영
- Thickness가 상대적으로 쉬운 이유 (임원 설명용 근거)
  - CD-SEM처럼 정교한 위치 지정이 필요 없음
  - 패턴 인식 난도가 낮음
  - 셋업 절차를 뒤로 미뤄도 문제없음 (일단 측정하고 나중에 보정 가능)
- **Thickness는 조건부 목표**: SecureVDI 경유라 2027 입력 주입 테스트 통과가 조건. 막히면 VDI 안 설치 대안을 협의하고, 그것도 안 되면 2029 완성 목표를 CD-SEM 하나로 줄임

**완성의 뜻**

| 항목 | 결정 |
|---|---|
| 범위 | 셋업 수요(월 건수)의 ⟨확인⟩%를 차지하는 상위 빈도 레시피 유형 |
| 대상 작업 | 레시피 의뢰서 기반 신규 셋업과 측정 파라미터 추가. 그 밖의 기존 레시피 튜닝은 2030 이후 |
| 자율 기준 | 자율 완주율(예정에 없던 개입 없이 끝까지 진행) ≥ ⟨확인⟩% |
| 남기는 승인 | 최종 저장·적용 승인 1회. 예정된 개입이라 세지 않음 |
| 자체 중단 | 특이 사항·위험 때 Agent가 스스로 멈추고 엔지니어를 부른 건수. 따로 세고 실패로 보지 않음 |
| 임원 보고 대표 숫자 | 2027 기준선 대비 건당 셋업 시간 ⟨확인⟩% 단축, 회수한 엔지니어 시간(월) |

**신뢰도 지수 (사용자 추가 제안)**
- 단위: 레시피 유형 × 절차 단계. 레시피 유형 신뢰도는 단계 신뢰도를 묶은 요약
- 신뢰도가 높은 단계는 엔지니어가 실시간으로 지켜보지 않아도 흘러감. 최종 저장 승인은 2029에도 유지하고, 저장 승인 생략은 오조작 0건이 쌓인 뒤 2030에 검토
- 계산 원칙 (숫자는 2028 데이터로 정함)
  1. 최근 ⟨N⟩건의 자율 완주율로 계산
  2. ⟨M⟩건 미만이면 신뢰도를 매기지 않고 엔지니어가 지켜봄
  3. 실패나 자체 중단이 한 번이라도 나면 그 단계는 즉시 "지켜보기 필요"로 내려감
  4. VLM 모델, 플랫폼, 장비 화면, 절차가 바뀌면 초기화

**2029 다른 장비군의 목표 상태**
- VeritySEM: 보조 단계 통과 (SecureVDI 경로 입력 대행 운영)
- 2차 장비군: 관찰·지식화 통과
- 2030 회사 목표(ARC Agent 완성)는 "CD-SEM·Thickness의 자율을 다른 장비군으로 넓히는 일"이 됨
