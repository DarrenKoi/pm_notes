# 장비 데이터를 장비 PC 설치 없이 읽을 경로 확인

## Question

2단계(2028)에서 읽을 **장비 데이터**(레시피 파일, 측정 결과, 로그, 측정 이미지)를 장비 PC에 아무것도 설치하지 않고 읽기 전용으로 가져올 수 있는가? 회사에서만 확인할 수 있는 일이라 사람이 한다 (HITL).

확인 목록:
- [ ] 장비군별로 데이터가 어디에 쌓이는가 (장비 PC 로컬, 공유 폴더, 장비 서버)
- [ ] 엔지니어 PC나 사내 서버에서 읽을 수 있는 경로가 있는가 (공유 폴더, RCS·Radmin 파일 전송, 장비 서버 조회)
- [ ] 읽기 권한과 보안 승인 절차
- [ ] SecureVDI 경유 장비군(VeritySEM·Thickness)도 같은 경로가 되는가

2028 계획(08)을 세우기 전까지만 답이 있으면 된다. 지금 막고 있는 티켓은 없다.
