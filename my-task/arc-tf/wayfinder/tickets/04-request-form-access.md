# 레시피 의뢰서 시스템을 읽기 전용으로 읽을 수 있는지 확인

## Question

1단계에서 읽기로 한 **레시피 의뢰서**(패턴 스키마, 좌표, 파라미터 등)를 프로그램이 읽기 전용으로 가져올 수 있는가? 회사에서만 확인할 수 있는 일이라 사람이 한다 (HITL).

확인 목록:
- [ ] 의뢰서가 있는 시스템과 담당 조직 (이름은 사내용 문서에만)
- [ ] 읽기 방법: DB 직접 조회, API, 파일 내보내기 중 무엇이 되는가
- [ ] 읽기 전용 계정, 권한 신청 절차와 걸리는 기간
- [ ] 의뢰서 한 건의 필드 구성 (패턴 스키마, 좌표, 파라미터 외에 무엇이 있는가). 필드 이름만, 값은 적지 않음
- [ ] 의뢰서와 실제 레시피를 이어 줄 키가 있는가 (레시피 이름, 제품, 공정 등)

결과로 적을 것: 가능 여부, 방법, 권한 신청 기간. 기간이 길면 1단계 일정의 앞부분에 걸린다.
