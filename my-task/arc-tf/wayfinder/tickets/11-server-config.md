# 서버 구성과 라이선스 확정

## Question

[서버 스택 조사](01-server-stack.md) 결과로, 기획안 요청 사항에 넣을 **서버 구성**을 무엇으로 확정하는가?

정할 것:
- 객체 저장: MinIO 커뮤니티판(유지보수 종료, AGPLv3)을 그대로 쓰는가, 다른 객체 저장으로 바꾸는가, 사내에 이미 있는 저장소를 쓰는가
- 큐·세션: Redis 8(라이선스 선택 필요)인가 Valkey(BSD-3)인가
- PostgreSQL 추가 여부 (사용자·권한·감사 기록)
- 사내 라이선스 검토를 누가, 언제 받는가 (회사 PC 설치 금지 목록·라이선스 확인 절차와 같은가)
- 서버를 TF가 직접 운영하는가, 인프라 조직에 맡기는가

결과로 적을 것: 확정한 구성, 라이선스 검토 담당과 시점. 기획안 6절 요청 사항의 "지식 자산 DB용 사내 서버"가 이 답을 쓴다.
