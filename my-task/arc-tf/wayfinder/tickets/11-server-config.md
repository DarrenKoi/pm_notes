# 서버 구성과 라이선스 확정

## Question

[서버 스택 조사](01-server-stack.md) 결과로, 기획안 요청 사항에 넣을 **서버 구성**을 무엇으로 확정하는가?

정할 것:
- 객체 저장: MinIO 커뮤니티판(유지보수 종료, AGPLv3)을 그대로 쓰는가, 다른 객체 저장으로 바꾸는가, 사내에 이미 있는 저장소를 쓰는가
- 큐·세션: Redis 8(라이선스 선택 필요)인가 Valkey(BSD-3)인가
- PostgreSQL 추가 여부 (사용자·권한·감사 기록)
- 사내 라이선스 검토를 누가, 언제 받는가 (회사 PC 설치 금지 목록·라이선스 확인 절차와 같은가)
- 서버를 TF가 직접 운영하는가, 인프라 조직에 맡기는가

결과로 적을 것: 확정한 구성, 라이선스 검토 담당과 시점. 기획안 6절 요청 사항의 "지식 자산 DB용 사내 서버"가 이 답을 쓴다.

## Resolution

2026-11-06 grilling에서 정함. 서버는 새로 사지 않고 **사내 서비스에서 할당**을 받음. 서비스 이름과 사양은 사내용 문서에만.

**구성 (모두 인프라 조직이 운영)**

| 데이터·일 | 둘 곳 | 할당 |
|---|---|---|
| 화면 이미지 (관찰 프레임, 녹화 원본, 중요 프레임) | 사내 MinIO | 2027 요청 10TB (🔶 추정) |
| 프레임 메타데이터, 지식 자산 검색 (하이브리드 + RRF) | 사내 OpenSearch 3.7.0, `arc-*` 인덱스 | 기존 100GB로 2027 운영, 증설은 2027-12 판단 |
| 사용자, 권한, 감사 기록 | 사내 PostgreSQL | 2~8GB |
| 큐, 세션, VLM 호출 제한 | 사내 Redis | 2GB |
| 예비 | 사내 MongoDB | 16GiB. 1단계는 쓰지 않음. OpenSearch 용량 부족이나 구조가 자주 바뀌는 문서가 생길 때 사용 |
| 애플리케이션 (이벤트 수신, 녹화 재처리, 채팅 백엔드) | 기존 VLM 서버 (vLLM + Flask 웹 앱, H200 2장) | 기존 자원 |

- 라이선스 검토는 서버 구성 요소가 모두 사내 서비스라 TF 몫이 아님. TF는 **엔지니어 PC 설치 프로그램의 라이브러리**만 회사 설치 금지 목록·라이선스 확인 절차로 검토받고, 2027-03 보안 승인 요청과 같이 냄
- 확인 남음: OpenSearch k-NN 검색에 쓸 노드 메모리 여유 (인프라 조직에 문의)

**화면 수집 두 가지 모드**

| 모드 | 언제 | 방식 | 업로드 |
|---|---|---|---|
| 상시 관찰 | 프로그램이 켜져 있는 동안 | 조작 영역이 바뀌고 화면이 멈추면 JPEG 1장 | 평균 300kbps 이하 |
| 녹화 | 엔지니어가 셋업 녹화를 시작할 때, Align Fail 대응 중 | 초당 10장 낱장 캡처 (빠른 마우스 조작을 놓치지 않으려면 필요, 예전 시험 근거) | 녹화 중에만 예외. 상한 약 5Mbps, 넘치면 PC 대기열(1GB)에 쌓았다가 나중에 올림 |

녹화 흐름:
1. PC가 이전 프레임과 완전히 같은 프레임을 버림 (상시 관찰과 같은 변화 판정 코드, 문턱값만 다름)
2. 원본을 서버에 임시 보관
3. 서버 재처리로 중요 프레임만 영구 보관: 조작 직전·직후, 화면 전환, 값 변경, 팝업·경고
4. 원본은 절차서 확정 또는 30일 중 먼저 오는 때에 삭제

**라이브 영역 처리** (측정 장비 화면에는 실시간 영상이 계속 바뀌는 영역이 있음)
- 셀 엔지니어가 장비군마다 **화면 영역 지도**(라이브 영역 / 조작 영역)를 정함. 2027-01~02 온보딩 기간에 대표 화면 몇 개
- 변화 신호는 조작 영역에서만 받음. 라이브 영역은 영역 대부분(시작값 타일 80%, 실측으로 조정)이 한꺼번에 바뀔 때만 장면 전환 신호로 씀. 저장 사진에는 라이브 영역을 그대로 담음
- 영역은 창 크기에 대한 비율 좌표로 적고, 장비 뷰어 창은 크기를 고정 (SecureVDI의 전체 화면·배율 100% 규칙을 로컬 RCS 창에도 적용). 창 크기가 바뀌면 프로그램이 알림
- 시험 도구: [observe_probe.py](../tools/observe_probe.py) (변화 판정·라이브 영역 마스크, `--selftest` 포함)
