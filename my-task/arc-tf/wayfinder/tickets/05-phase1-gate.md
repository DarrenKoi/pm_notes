# 2027 단계의 통과 기준 (Align Fail 자동 대응 + 관찰·지식화)

## Question

2027년 말에 1단계를 **통과했다**고 판단할 기준과 지표는 무엇인가? 2027년의 성과 과제는 **Align Fail 자동 대응**이고, 관찰·지식화는 바탕으로 같이 간다. 두 가지의 기준을 따로 정한다.

Align Fail 자동 대응에서 정할 것:
- 완성의 뜻: 실알람 무인 대응을 현장에서 운영하는 상태인가, 반자동(위치 재조정 자동, 확정은 엔지니어)인가
- 어느 장비군까지인가: CD-SEM만인가, VeritySEM·Thickness(SecureVDI 경유)도인가
- 성과 지표 후보: 자동 해결률, 알람 대응 시간, 회수한 장비 가동 시간, 엔지니어 호출 횟수. PoC 수치는 사내용 문서에만

관찰·지식화에서 정할 것 (셋업 시간 단축은 2028부터 약속하므로 여기에 넣지 않음):
- 후보 지표: 장비군별 절차서 수, 지식 자산 건수, 돌파구 추천 채택률, 막힘 해결 시간, 채팅 응답 만족도, 엔지니어 PC 자원 사용 한도 준수, 관찰 정확도(레시피 상태를 맞게 읽은 비율).

기존 기획안 5절의 단계 통과 결정 방식(리드 정리 → 담당 엔지니어 품질 확인 → 월간 임원 보고 승인, 미달 시 보완·축소·중단)을 그대로 쓰는지도 함께 정한다.

## Resolution

2026-11-06 grilling에서 정함.

**Align Fail 자동 대응 (2027 성과 과제)**

| 항목 | 결정 |
|---|---|
| 완성 상태 | 상반기 반자동 상시 운영(실알람에서 위치 재조정 자동, 확정은 엔지니어) → 하반기 자동 해결률 기준을 넘은 장비부터 무인 대응으로 전환 |
| 장비군 | 통과 기준은 CD-SEM만. VeritySEM 시범 적용은 통과 기준 밖의 확장 목표 |
| 통과 지표 | 자동 해결률 (실알람 중 사람 없이 해결된 비율) ≥ ⟨확인⟩% |
| 임원 보고 대표 숫자 | 회수한 장비 가동 시간 (월 시간) |
| 같이 보는 지표 | 알람에서 해결까지 걸린 시간, 엔지니어 호출 횟수 |
| 가드레일 | 잘못된 위치로 측정을 이어간 건수 0 |
| 목표 수치 | PoC 실측이 있으므로 지금 정함. 숫자는 사내용 문서에만, 공개 문서는 ⟨확인⟩ |

**관찰·지식화 (플랫폼 바탕)**

통과 기준은 세 가지만 둠.
1. 1차 3개 장비군마다 대표 레시피 유형의 절차서 ⟨N⟩개 이상 (AI 초안 + 엔지니어 검토)
2. 요청형 돌파구 추천이 실제로 쓰이고, 채택률 ⟨확인⟩% 이상
3. 엔지니어 PC 자원 한도 준수 (실측값은 "엔지니어 PC 자원 실측과 Windows 버전 확인" 티켓)

단계 재현율, 엔지니어 수정률, 검토 시간, 채팅 만족도, 관찰 정확도는 월간 보고에서 보되 통과 판정에는 쓰지 않음. ⟨N⟩과 채택률 목표는 "시범 녹화로 절차 추출 정확도 실측" 결과로 정함.

**판정 방식**
- 두 관문은 따로 판정함. 2028 보조 단계로 넘어가는 조건은 **관찰·지식화 통과**. Align Fail은 성과 과제라 미달이어도 2028 진입을 막지 않고, 보완·축소 결정 대상이 됨
- 결정 절차는 기획안 5절과 같음: 리드 정리 → 담당 엔지니어 품질 확인 → 월간 임원 보고 승인, 미달 시 보완·축소·중단
- 2027-06 반기 점검 추가: Align Fail 무인 전환 여부, 관찰·지식화 중간 절차서 수 확인

> **2026-11-06 변경**: Align Fail 부분은 [2027 분기별 계획](07-phase1-plan.md)으로 바뀜. 장비군 CD-SEM + Thickness, 완성 시점 2027 상반기, 관문 판정 2027-06. 관찰·지식화 부분은 그대로임.
