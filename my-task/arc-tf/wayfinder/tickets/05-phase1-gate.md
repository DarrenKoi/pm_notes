# 2027 단계의 통과 기준 (Align Fail 자동 대응 + 관찰·지식화)

## Question

2027년 말에 1단계를 **통과했다**고 판단할 기준과 지표는 무엇인가? 2027년의 성과 과제는 **Align Fail 자동 대응**이고, 관찰·지식화는 바탕으로 같이 간다. 두 가지의 기준을 따로 정한다.

Align Fail 자동 대응에서 정할 것:
- 완성의 뜻: 실알람 무인 대응을 현장에서 운영하는 상태인가, 반자동(위치 재조정 자동, 확정은 엔지니어)인가
- 어느 장비군까지인가: CD-SEM만인가, VeritySEM·Thickness(SecureVDI 경유)도인가
- 성과 지표 후보: 자동 해결률, 알람 대응 시간, 회수한 장비 가동 시간, 엔지니어 호출 횟수. PoC 수치는 사내용 문서에만

관찰·지식화에서 정할 것 (셋업 시간 단축은 2028부터 약속하므로 여기에 넣지 않음):
- 후보 지표: 장비군별 절차서 수, 지식 자산 건수, 돌파구 추천 채택률, 막힘 해결 시간, 채팅 응답 만족도, 엔지니어 PC 자원 사용 한도 준수, 관찰 정확도(레시피 상태를 맞게 읽은 비율).

기존 기획안 5절의 단계 통과 결정 방식(리드 정리 → 셀 품질 확인 → 월간 임원 보고 승인, 미달 시 보완·축소·중단)을 그대로 쓰는지도 함께 정한다.
