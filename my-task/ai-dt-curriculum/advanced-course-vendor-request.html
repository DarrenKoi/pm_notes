진행 조건

  • 강의와 실습 비중: 강의 50%, 실습 50%
  • 2026년 커리큘럼 활용 가능 (2026년 과정에 없는 주제만 신규 개발)
  • Git, GitLab CI/CD는 2인 1조 토이 프로젝트로 진행, 발표 없음 (과정 중 팀 단위 Agentic Coding, Git, CI/CD의 자연스러운 습득 유도)
  • 실습 데이터: 업체 제작 가상 프로젝트와 데이터만 사용 (회사 데이터와 코드 반출 불가)
  • 사내 적용 범위 표시: Agent는 사내 전용으로 운영하고 모델은 사내 vLLM 기준. 주제별로 이 환경에서 적용 가능한 범위 표시

회신 요청 항목

  • 교육 가능한 주제 (2주 기간에 넣기 어려운 주제는 별도 과정으로 진행 가능, 예: 소형 LLM 파인튜닝, RE와 REA 활용법)
  • 모듈별 세부 커리큘럼과 시간 배분
  • 사내 폐쇄망 GitLab과의 차이 확인 사항 정리 (CI/CD 가능 범위 등, 당사가 확인 후 회신)
  • 견적: 1차수 금액과 4차수 총액
  • Agent 보안 레드팀 심화(공격 자동 생성 도구 포함)의 별도 과정 가능 여부, 신규 개발 여부, 견적
  • 투입 강사와 조교 인원, 강사 이력, 계약 후 개강까지 준비 기간
  • 수료 판정 방식과 산출물
  • 교재, 실습 코드, 평가 세트의 소유권과 사내 재사용 조건
