# 2026년 SK하이닉스 AI 교육 과정 개요

## 2027년 기반기술센터 교육 제안 요청

2026년 교육 과정은 2027년 기반기술센터 맞춤형 AI 교육을 설계하기 위한 참고 자료다. 교육 업체에 기반기술센터 구성원이 교육에서 배운 내용을 실제 업무에 적용할 수 있도록, 센터의 업무 특성과 교육 대상자의 역량을 반영한 커리큘럼을 제안해 달라고 요청한다.

업체 제안에는 다음 내용을 담아 달라고 요청한다.

- 교육 대상과 수준별 학습 목표, 과정별 권장 시간
- 기반기술센터 업무를 반영한 실습 과제, 사용 도구와 실습 환경, 수료 시 산출물
- 2026년 과정에서 활용할 내용과 센터 업무에 맞춰 수정하거나 추가할 내용

## 비개발 직군

### 1. AI자동화 활용 실습 과정

사내 규정과 반도체 기술 용어 등 현업 데이터를 활용한다. 코드를 직접 작성하지 않고 바이브 코딩과 Dify로 사내 AI 앱과 챗봇을 만든다. 이를 n8n과 연계해 업무 자동화 파이프라인을 처음부터 끝까지 구성한다.

**사용 도구** Dify, n8n

### 2. 생성형 AI 활용 업무 혁신

반도체 현장 문서를 바탕으로 생성형 AI 프롬프트를 설계하고 AI 비서(Skill, GPTs/Gems)를 만든다. 보고서·공정·시장·경쟁사 분석과 사내 지식베이스 구축에 적용해 업무 시간을 줄이고 인사이트를 도출하는 방법을 익힌다.

**사용 도구** Dify, n8n

## 개발 직군

### 1. AI 에이전트 프레임워크 구현

LangChain, LangGraph, RAG를 활용해 멀티 에이전트를 코드로 구현한다.

**사용 환경** API 키, 고사양 GPU

### 2. LLM활용과 고급화 과정

LLM의 구조와 학습 파이프라인을 이해하고 소형 언어 모델(sLLM)을 파인튜닝한다. RAG 심화 기법과 MCP를 활용해 특정 도메인에 맞춘 AI 에이전트를 구현한다.

**사용 환경** API 키, 고사양 GPU

### 3. 실전 AI 에이전트 Harness / 오케스트레이션

오케스트레이션 패턴 5개를 비교하고 적용할 패턴을 선택한다. 보안 샌드박스, 하네스, MCP를 통합 설계하고 가드레일을 적용해 제품 수준의 에이전트를 구현한다.

**사용 도구** Claude Code(유료), Claude Agent SDK, OpenAI API, LangGraph

### 4. 바이브코딩으로 완성하는 풀스택 서비스

AI를 활용한 개발 방법론을 적용하고 실무 중심의 아키텍처 개발 방법을 익힌다. 풀스택 서비스를 검증 가능한 MVP로 구현한다.

**사용 도구** Claude Code(유료), GitHub

### 5. Agent Evaluation & Observability

RAG와 에이전트의 핵심 구조를 검토하고 합성 데이터와 실행 기록을 이용해 평가셋을 만든다. Langfuse 트레이싱과 프롬프트 관리를 연계해 성능을 개선하는 과정을 단계별로 실습한다.

**사용 도구** Langfuse, Ragas, DeepEval, LangChain, LangGraph, Deep Agents

### 6. MLOps 및 Edge AI 배포

수율 예측과 공정 이상 탐지 등 반도체 데이터 사례를 다룬다. 실험 추적부터 모델 서빙·운영, 온프레미스·폐쇄망 엣지 배포까지 MLOps 전 과정을 직접 구축한다.

**사용 도구** Python, MLflow, Docker, ONNX/TensorRT
