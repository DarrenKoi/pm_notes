# AI/DT 교육 커리큘럼 설계

> 제조 회사에서 "1인 1Agent 개발(운영)"을 실행하기 위한 교육 과정 신설과 인증 체계 정리 방향을 논의하는 작업공간.

## 배경

- **목적**: 1인 1Agent 개발(운영) 실행 방안 도출 — 이를 위한 교육 과정 신설 + 인증 체계 정리 방향 논의
- **진행 방식**: 여러 분과를 운영하고, 각 분과가 커리큘럼을 정리해 발표 자료를 만든다.
