# 기반기술센터 AI Agent 고급 과정 커리큘럼 요청서

> 기반기술센터 구성원 대상 AI Agent 고급 과정(2주, 80시간)의 커리큘럼 제안 요청

## 1. 배경

- AX 확산으로 팀별 AI Agent 생성과 그 수는 지속 증가 추세인 반면, 전문적인 관리와 운영 노하우 부재
- 교육 목적: 1인 개발이 아닌 팀 단위 AI Agent 개발과 운영, 팀별 Agent 관리 역량을 갖춘 구성원(챔피언) 확보

## 2. 교육 대상 구성원

1. Agent를 혼자 개발하고 운영해 본 경험이 있는 구성원
2. 프로그래밍 언어 사용과 사내 시스템(HCP, DataLake) 활용이 가능한 구성원

위 역량은 선수 조건이며 과정에서 다시 다루지 않음

## 3. 과정 개요

| 항목 | 내용 |
|------|------|
| 대상 조직 | 기반기술센터 (2027년 센터 맞춤 과정) |
| 기간 | 연속 2주(10일), 하루 8시간, 총 80시간 |
| 인원 | 차수당 15명, 4차수, 총 60명 (검토 중) |
| 방식 | 대면 교육, 업체 교육장 (확정) |
| 실습 환경 | 업체 교육장 환경, public API 사용 (확정) |
| 개강 시기 | 협의 |

## 4. 커리큘럼 요청 범위

아래 주제를 포함한 세부 커리큘럼과 시간 배분 제안 요청

| 주제 | 다룰 내용 | 신규 개발 요청 |
| ------ | ----------- | ---------------- |
| Git, GitLab 기본 사용법 | 커밋, 브랜치, MR, 충돌 해결 | GitLab 기준 실습 전체 |
| 팀 단위 Agentic Coding | 여러 구성원이 각자의 코딩 Agent로 하나의 저장소를 개발하는 방법, Agent 지침 파일과 Skill 공유 | 1인 사용법을 팀 단위 사용법으로 확장 |
| AI 시스템용 GitLab CI/CD | Agent 테스트 자동화, 프롬프트와 모델 버전 관리, MR별 평가 게이트, 배포와 롤백 | GitLab CI 기준 실습, MR별 평가 게이트 |
| 소형 LLM 파인튜닝 | 반도체 도메인 데이터(이미지, 문서, 사내 데이터 유형) 적용 방법, 튜닝 모델의 vLLM 배포와 운영 | 이미지와 문서 데이터 적용, vLLM 배포와 운영 |
| RAG 동향과 AI용 DB 운영 | RAG 최신 동향 파악과 실습, AI가 쓰는 지식 저장소 운영법 (온톨로지, LLM wiki) | 온톨로지, LLM wiki 구축과 운영 |
| RE (Reverse Engineering)와 REA 활용법 | 코딩 Agent를 이용한 기존 프로그램 분석, REA 사용법 | 전체 |
| Agent 모니터링과 테스트 | 실행 추적, 품질, 비용, 응답 시간 모니터링, 평가셋 구축, Agent 테스트 방법 | - |
| LLMOps | 캐싱, 모델 운영 최적화 (모델 라우팅, 서빙 최적화), 지연, 토큰, 비용 관리 | 캐싱, 모델 라우팅 |
| Agent 보안 설계 | prompt injection 방어, harness 구축, 도구 권한, 샌드박스 | - |

선택 견적 대상 추가 과정: Agent 보안 레드팀, 평가 설계 심화

## 5. 진행 조건

- 강의와 실습 비중: 강의 50%, 실습 50%
- 2026년 커리큘럼 활용 가능 (2026년 과정에 없는 주제만 신규 개발)
- Git, GitLab CI/CD는 2인 1조 토이 프로젝트로 진행, 발표 없음 (과정 중 팀 단위 Agentic Coding, Git, CI/CD의 자연스러운 습득 유도)
- 실습 데이터: 업체 제작 가상 프로젝트와 데이터만 사용 (회사 데이터와 코드 반출 불가)

## 6. 회신 요청 항목

- 모듈별 세부 커리큘럼과 시간 배분
- 모듈별 2026년 과정 재사용, 수정, 신규 개발 구분
- 사내 폐쇄망 GitLab과의 차이 확인 사항 정리 (CI/CD 가능 범위 등, 당사가 확인 후 회신)
- 견적: 1차수 금액과 4차수 총액, 선택 견적은 과정별 분리
- 투입 강사와 조교 인원, 강사 이력, 계약 후 개강까지 준비 기간
- 수료 판정 방식과 산출물
- 교재, 실습 코드, 평가 세트의 소유권과 사내 재사용 조건
