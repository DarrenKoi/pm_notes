# 기반기술센터 AI Agent 고급 과정 커리큘럼 요청서

> 기반기술센터 구성원 대상 AI Agent 고급 과정(2주, 80시간)의 커리큘럼 제안 요청

## 1. 배경

- AX 확산으로 팀별 AI Agent 생성과 운영 증가, 그 수는 지속 증가 추세
- 교육 목적: 수료 구성원의 고품질 AI Agent 개발과 운영, 소속 팀 Agent 관리 역량 확보

## 2. 교육 대상 구성원

1. Agent를 혼자 개발하고 운영할 수 있는 구성원
2. 프로그래밍 언어(Python, SQL, JavaScript 등) 사용과 사내 시스템(HCP, DataLake) 활용이 가능한 구성원

위 역량은 선수 조건이며 과정에서 다시 다루지 않음

## 3. 과정 개요

| 항목 | 내용 |
|------|------|
| 대상 조직 | 기반기술센터 (2027년 센터 맞춤 과정) |
| 기간 | 연속 2주(10일), 하루 8시간, 총 80시간 |
| 인원 | 차수당 15명, 4차수, 총 60명 (검토 중) |
| 방식 | 대면 교육, 업체 교육장, 2인 1조 실습 |
| 개강 시기 | 협의 |

## 4. 커리큘럼 요청 범위

아래 주제를 포함한 세부 커리큘럼과 시간 배분 제안 요청. 2026년 운영 과정의 재구성을 기본으로 하고, 없는 부분만 신규 개발

| 주제 | 다룰 내용 |
|------|-----------|
| 팀 개발용 Git, GitLab | 브랜치, MR, worktree, 충돌 해결, 팀 개발 규칙 |
| 팀 단위 Agent 협업 개발 | 저장소 공유 컨텍스트 파일, 팀 공용 rule과 skill, 결정 기록, 사람과 Agent 간 작업 인계, MR 리뷰 Agent |
| AI 시스템용 GitLab CI/CD | Agent 테스트, 프롬프트와 모델 버전 관리, MR별 평가 게이트, 배포와 롤백, 사내 폐쇄망 GitLab과의 차이 |
| LLMOps (운영과 최적화) | Phoenix 추적, 지연, 토큰, 비용 지표, 캐싱, 모델 라우팅, 장애 탐지 |
| 소형 LLM 파인튜닝 | 파인튜닝, RAG, 프롬프트 중 선택 기준, 증류, LoRA/QLoRA, 평가, 서빙 |
| RAG 동향 | Hybrid 검색, Reranking, Agentic RAG, GraphRAG, 멀티모달 RAG |
| Agent 권한과 도구 통제 | 도구별 허용 범위, 실행 샌드박스, 사람 승인 흐름, MCP 서버 권한, 감사 로그 |
| 통합 과제 | 조별 저장소에 모듈별 실습 누적, 최종 발표, 소속 팀 전파용 자료 작성 |

선택 견적 대상 추가 과정 (과정별 12시간): RAG 심화, Agent 보안 레드팀, 평가 설계 심화

## 5. 진행 조건

- 교육 장소: 업체 교육장 (수강생이 업체 교육장으로 참석)
- 실습 환경: 업체 교육장 환경 사용. 사외 진행이므로 public API(Claude, Codex) 사용 가능
- 실습 비중: 강의 30%, 실습 70%
- 실습 데이터: 업체 제작 가상 프로젝트와 데이터만 사용 (회사 데이터와 코드 반출 불가)

## 6. 회신 요청 항목

- 모듈별 세부 커리큘럼과 시간 배분
- 모듈별 2026년 과정 재사용, 수정, 신규 개발 구분
- 견적: 1차수 금액과 4차수 총액, 선택 견적은 과정별 분리
- 투입 강사와 조교 인원, 강사 이력, 계약 후 개강까지 준비 기간
- 수료 판정 방식과 산출물
- 교재, 실습 코드, 평가 세트의 소유권과 사내 재사용 조건
