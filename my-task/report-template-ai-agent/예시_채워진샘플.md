## 장표 2 — 상반기 로드맵 이행 총괄

| 과제명 | H1 계획 | 실적 | 이행도 | 상태 | 미달 사유 | 하반기 목표 (H2 기준선) |
|--------|---------|------|--------|------|-----------|-------------------------|
| 검사 리뷰 자동화 에이전트 | PoC 완료 | PoC 완료·1개 라인 확대 | 100% | 🟢 | — | Q4까지 전 라인(12개) 상용 이관 |
| 설비 로그 진단 에이전트 | 진단 정확도 80% | 정확도 68% (파일럿 라벨 500건 기준) | 79% | 🟡 | 학습 로그 편중, 희소 이상 미검출 | 데이터 보강·재학습으로 정확도 80% 달성 |
| 리포트 초안 생성 에이전트 | 파일럿 착수 | 요구정의만 완료 | 30% | 🔴 | 담당 인력 타 과제 투입으로 착수 지연 | Q3 파일럿 완료·현업 정성 평가 확보 |

> 이행도 모수: 검사 리뷰 = "PoC 완료" 자체를 100, 로그 진단 = 목표 정확도 80% 대비, 리포트 = 파일럿 착수 단계 대비.

**총평 (부서 롤업):** 3개 과제 · 🟢 1 / 🟡 1 / 🔴 1 — 1개 정상 이행, 로그 진단은 데이터 편중으로 부분 이행, 리포트는 인력 배치로 지연.

> 🎤 발표 스크립트: 검사 리뷰 자동화는 계획대로 PoC를 끝내고 한 라인에 붙였습니다. 로그 진단은 정확도가 목표에 못 미쳤는데, 학습 데이터가 특정 패턴에 쏠린 게 원인입니다. 리포트 생성은 인력이 다른 과제로 빠지며 착수가 늦었고, 이 부분은 솔직히 지연입니다.

## 장표 3 — 대표 과제 심화 — 검사 리뷰 자동화 에이전트

**한 줄 요약:** 검사 이미지 리뷰를 사람이 눈으로 판정하던 과정을 VLM 에이전트가 1차 선별하도록 자동화.

- **As-Is (도입 전):** 리뷰어가 이미지를 전수 육안 판정 → 물량 몰릴 때 대기·판정 편차 발생.
- **To-Be (도입 후):** 에이전트가 정상/이상 1차 선별, 사람은 이상 후보만 확인 → 리뷰어는 판단에만 집중.
- **증거 (효과):** 리뷰어 직접 확인 물량 주 320건 → 45건 (약 86%↓). 파일럿 라인 기준, 리뷰 대기시간도 눈에 띄게 단축.
- **사용범위 (수용도):** 파일럿 1개 라인·리뷰어 3명이 상시 사용 중. "의심 케이스만 보면 돼 판정이 편해졌다"는 현업 피드백.
- **vs 계획:** 상반기 계획(PoC 완료) 달성. 다만 상용 이관은 하반기 과제로 남음.

> 🎤 발표 스크립트: 예전엔 리뷰어가 모든 이미지를 다 봐야 했습니다. 지금은 에이전트가 걸러주고 사람은 의심 케이스만 봅니다. 한 라인 파일럿에서 직접 확인 물량이 320건에서 45건으로 줄었습니다. 계획했던 PoC는 끝났고, 남은 건 전 라인 상용화입니다.

## 장표 4 — 이슈·리스크 · 하반기 중점

**주요 이슈·리스크**
- `[통제가능]` 로그 진단 에이전트: 학습 데이터가 흔한 이상 패턴에 편중 → 데이터 보강으로 해소 가능.
- `[외부의존]` 리포트 생성 에이전트: 전담 인력이 타 과제에 묶여 있어, 인력 재배치 없이는 하반기도 지연 가능.

**하반기 중점 방향** (대표 1개 마일스톤까지)
- 검사 리뷰 자동화: Q3 3개 라인 확대 → Q4 전 라인 상용 이관 / 완료 기준: 전 라인에서 리뷰어 직접 확인 물량 80%↓ 유지.
- 로그 진단: 희소 이상 데이터 보강 후 재학습으로 정확도 80% 재도전.

> 🎤 발표 스크립트: 가장 큰 리스크는 로그 진단의 데이터 편중인데, 이건 우리가 데이터 보강으로 잡을 수 있습니다. 하반기에는 검사 리뷰 자동화를 전 라인으로 넓히는 것을 반드시 넘기겠습니다.
