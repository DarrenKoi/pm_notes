# my-task 문체와 표현 기록

> my-task 산출물을 쓸 때 따르는 회사 문체, 표현, 장표 스타일의 누적 기록. 문서를 쓰기 전에 읽고, 사용자가 표현이나 문체를 고쳐 달라고 하면 그 자리에서 여기에 한 줄을 더한다.

## 쓰는 법

- 문서를 새로 쓰거나 고치기 전에 이 파일을 먼저 읽음
- 사용자가 수정 요청을 하면 문서를 고친 뒤, 다른 문서에도 적용될 규칙이면 해당 절에 추가 (날짜, 고치기 전 → 고친 후, 이유)
- 그 문서 한 곳에만 해당하는 수정은 기록하지 않음
- 기존 규칙과 부딪히면 새 지시가 우선이고, 옛 규칙은 지움
- 사용자가 직접 말한 것과 에이전트의 해석은 구분해 적음 (해석은 "해석"이라고 표시)

## 1. 문체

| 자리 | 규칙 | 예 |
|------|------|-----|
| 목록, 표 칸 | 개조식, 마침표 없음 | - |
| 개조식 종결 | `~듦`, `~함`보다 명사형 종결 우선 (2026-11-09) | "시간이 듦" → "시간 지연", "시간이 부족했음" → "시간 부족", "Agent가 돎" → "Agent 운영" |
| 서술 문단 | `~입니다`, `~습니다` 경어체 | - |
| 금지 | `~다`, `~한다` 평서체 (2026-11-06) | - |

## 2. 기호와 표기

- em dash(—)와 가운데 점(·)을 쓰지 않음 (2026-11-06). 나열은 쉼표나 "와/과", 부연은 괄호나 문장 분리, 제목 구분은 콜론, 표의 빈칸은 "-"
- 근거 수치가 없으면 지어내지 않고 `⟨확인: 무엇을⟩` 자리로 남김. docx로 낼 때는 `<>`로 바꿈
- 기술 용어는 한국어에 영어 병기

## 3. 표현 사전 (쓰지 않는 말 → 쓰는 말)

| 쓰지 않는 말 | 쓰는 말 | 이유 | 날짜 |
|-------------|---------|------|------|
| 무인 대응, 무인 전환, 무인 운영, 24h 무중단 | 자동 대응 | "무인"은 만일의 경우 책임질 사람이 없다는 오해를 낳음. 엔지니어가 자리에 있고 결과를 책임짐 | 2026-11-08 |
| Smart Align Agent 등 "Smart" 수식어 | Align 자동 대응 Agent (하는 일 그대로의 이름) | "Smart를 붙이면 Smart가 아님" | 2026-11-08 |
| "사람이 없어도 됨" 식의 효과 논리 | "엔지니어가 하던 일을 멈추지 않아도 됨", "대응 대기 축소" | 위와 같음 | 2026-11-08 |
| 실명 | 직책명 | 저장소에 실명을 남기지 않음 | 2026-11 |

## 4. 내용 구성

- 과제, 성과 항목은 기능(What)보다 **문제 → 안 하면 생기는 일 → 효과 → 측정 지표**를 먼저 씀 (2026-10-08, 순서와 4문항 구성은 해석)
- 화면 입력 자동화는 "제어권 인계"(입력 몇 초만 넘겨받음)로 설명

## 5. 장표 (pptx)

구현 예는 `arc-tf/deliverables/build_pptx.py`, 상세는 `arc-tf/deliverables/pptx-template.md`. 2026-11-16 확정.

- 회사 마스터 슬라이드에 옮겨 쓰므로 footer, 로고, 쪽 번호, 제목 아래 가로선을 그리지 않음
- 제목 26pt 볼드 좌측 상단. 요약문은 제목 아래 한 줄, 20pt 볼드 가운데 정렬, 검정 글자에 중요 문구만 파랑. 요약문은 지우지 않음
- 본문은 1.55~6.95 inch, 좌우 여백 0.5 inch. 아래를 비우지 않고 6.95 inch까지 채움
- 색은 밝은 회색, 연회색 바탕에 검정 글자 위주. 강조 상자만 검정 바탕에 흰 글자. 짙은 파랑으로 채운 상자는 쓰지 않음
- 파랑은 진한 색 하나만 (연한 파랑은 "연하다"는 지적). 주황은 관문, 최종 목표, ⟨확인⟩ 자리에만
- 연결선은 얇고 진한 회색. 두껍고 희미한 선은 쓰지 않음
- 2 컬럼으로 전과 후를 나누는 구성 선호 (좌: 이슈, 기존 / 우: 해결, 개선)
- 볼드와 밑줄 강조를 섞어 씀
- "headline"이라는 말은 요약문인지 제목 아래 선인지 먼저 확인
- Bento(HTML) deck은 하얀 배경, 강조색은 진한 색 하나
