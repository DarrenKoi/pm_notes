# AIX 재사용 가이드

특정 장비의 실적을 쓰기 전에 기획과 기술 설계의 질문을 익히는 공간이다. 강의 원문과 실제 프로젝트 입력값을 분리한다.

1. [기획 방법론](./01-기획문서_AX서비스기획.md): 왜 이 과제인가→업무/문제/원인→적정성→가치 검증/실행 전략.
2. [기술 방법론](./02-기술문서_AI과제정의구현.md): 과제 정의→역할과 흐름→KSF/제약→개발 일정.
3. [과제 발굴 빈 양식](./00-템플릿_AI과제발굴/README.md): 실제 회의·개인 작성에 입력할 칸과 작성 도움말. 양식19개를 개별 검토했고 원래 작성 칸/고유 예시는 유지했다.

두 방법론은 질문과 판단 기준, 빈 양식은 입력 도구여서 유사 설명을 무조건 합치지 않는다. [강의 출처](../lectures/README.md)의 M1~M9 모듈과 12-Step 번호를 구분하고 조직별 업무 레벨을 먼저 합의한다. 작성 예시의 숫자는 측정값을 대신하지 않는다. 현재 사내 정책/승인·PoC 결과와 원본 추출 완전성은 미확인이다.
