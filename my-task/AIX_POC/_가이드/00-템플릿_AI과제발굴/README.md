# AI 과제 발굴 입력 양식 목차

[전체 단계/파일 목차](./00-README.md)를 대표 인덱스로 유지한다. 기존 참조와 작성 규칙을 보호하기 위해 파일명을 바꾸지 않았다.

- 개인 학습: [빠른 시작](./00A-개인용-빠른시작.md)→[한 장 워크북](./00B-개인용-1페이지-워크북.md)→01~11 본 양식→[자가점검](./자가점검-체크리스트.md).
- 워크숍: [진행 안내/11단계 목록](./00-README.md)→01~05→[05A 데이터 진단](./05A-데이터준비도-진단.md)→06~10→11.
- 보완: [가상 초안/완성 예시](./예시모음_초안에서-완성.md)로 문체/근거를 대조하고 [보강 질문](./보강노트_놓치기쉬운-항목.md)으로 적용 조건을 확인한다.

학습 완료는 빈칸·추가 질문을 찾은 상태일 수 있다. 실행 착수는 측정/추정 근거·리스크·비용·담당자 승인을 별도로 갖춰야 한다. 과거 [작성 브리프](./_internal/SPEC.md)는 설계 이력이며 현행 기술 정확성을 보장하지 않는다.

7문항 키트의 전략2/성과3/실행2는 [상위 기획 방법론](../01-기획문서_AX서비스기획.md)의 전략2/성과4/실행1을 재구성한 것이다. 같은21점이어도 점수를 직접 비교하지 않는다. 통일/통합 판단은 Claude연결 부재로 보류하고 각 입력칸·고유 예시는 보존했다.

시간 절감은 ROI와 구분하고[05](./05-과제적정성-검토.md)에 비용/단위/기간을 정의한다. 운영 점수와 정확도는[08](./08-to-be-프로세스.md)의 평가 조건을 확인한다. 미확인은△,해당 없음은 근거 있는 제외로 남긴다.
