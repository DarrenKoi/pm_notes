# CD-SEM 단계별 실행기획 읽기 안내

[00-README 단계/파일 목록](./00-README.md)을 대표 인덱스로 유지한다. 01→02→03→04→05에서 목표·범위·Pain/원인·가치 조건을 읽고,06→07→08→09→10→11에서 정의서·흐름·제약·일정·검산을 대조한다.

상세 문서는 판단/근거 추적용, `_장표.md`와 통합 덱은 발표 밀도/형식으로 만든 파생본이다. 목적과 고유 발표 문맥이 달라 원문을 삭제/합치지 않았다. 상세/장표/SPEC 원문24개는 모두 개별 검토했고 현재 조건은 상세 본문의 검토 절을 대표로 읽는다. 기존 PPTX/HTML은 보호하며 현재 주석을 반영해 재생성하지 않았다.

2026-06의 `확정`·✅·편차0·24시간은 당시 합의·목표·문서 상태와 분리해 읽는다. 지금 실행/승인된 사실로 사용하지 않는다. 01의L0~L3 전략 연계와02의L1~L5 업무 분해는 다른 척도다. 원문에 전체②~⑥ 계획과 좁은Align fail PoC가 섞여 있어 적용전 범위를 확인해야 한다.

[PoC 실험 설계의 현재 보완 조건](../05-적용_CDSEM_PoC실험설계.md)에서 정답/분할/좌표·성공률/검출·미확정 판정을 확인한다. 당시 발표물은 보완 절이 반영된 결과물이 아니다.
