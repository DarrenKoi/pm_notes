# RAG 사이트 분석과 평가 읽기

외부 RAG 벤치마크를 관찰하고 그 결과를 적용할 조건을 정리한다. 이 폴더는 사이트 관찰 기록과 평가 해석을 다루며 독립적으로 읽는다.

## 읽기 순서

1. [벤치마크 읽기](benchmark-reading.md): 지표의 목적, 작동 방식과 재현 조건을 먼저 이해한다.
2. [BAEUM.AI 사이트 관찰 기록](rag_baeum_site_analysis.md): 2026-07-09 당시 화면과 수치다. 현재 순위·가격은 미확인이다.
3. [정리 기록](organization-log.md): 출처, 문서별 검토 결과와 검증 한계를 확인한다.

## 문서의 역할

- 학습: `benchmark-reading.md`는 평가를 해석하는 절차다.
- 과거 기록: `rag_baeum_site_analysis.md`는 관찰 당시 화면의 상세 기록이다. 새로운 결과로 덮어쓰지 않는다.
- 관리: `organization-log.md`는 정리와 검증 근거다.
