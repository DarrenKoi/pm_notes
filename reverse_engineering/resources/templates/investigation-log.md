## 5. 정적 분석 경로

주소는 `모듈 + RVA`(예: `RecipeTool.exe+0x12340`)로 적는다. Ghidra 화면의 주소(VA)는 이미지 베이스에 따라 바뀔 수 있다.

| 모듈 + RVA | 제안 이름 | 하는 일(한 문장) | 이름의 근거 | Evidence ID | 등급 |
|---|---|---|---|---|---|
| | | | 참조 문자열, 임포트, 호출 관계 | | 관찰 / 추론 |
