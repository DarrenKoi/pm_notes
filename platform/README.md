# 사내 AI Agent·Skill 공유 관리 플랫폼

> 사업부 구성원이 AI Agent와 Skill을 안전하게 공유·사용하고, 검증된 자산을 전사 플랫폼으로 승격하는 1차 플랫폼이다.

**확정 전제**

- 1차 플랫폼은 사업부(Biz)마다 **별도 인스턴스로 각각 배포**한다(멀티테넌시 아님). 2차 전사 플랫폼은 그 상위에 별도로 존재한다.
- **"Agent"는 포괄적 용어**다. 다루는 자산은 **Skill / MCP server / 팀 서버가 운영하는 hosted agent** 세 종류이고, 셋의 배포·심사·폐기 경로가 다르다.
- **오픈소스 런타임을 포함**해 여러 런타임이 공존한다. 카탈로그는 런타임 중립, 런타임 차이는 어댑터로 흡수한다.
- 사내 IdP subject identifier 는 **public**이고, 전 사원 ID·이름 **단일 마스터 테이블**이 있다. 레지스트리는 사용자 정보를 소유하지 않는다.
