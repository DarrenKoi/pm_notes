# 테스트 학습 목차

1. [단위 테스트 기초](./unit-testing-basics.md): 테스트 목적·AAA·경계값·mock·TDD를 배운다.
2. [프레임워크 사용](./testing-frameworks.md): pytest/unittest·Vitest/Jest·Mocha 도구 설정과 용도를 비교한다.
3. [E2E 기초](./e2e-testing-basics.md): 브라우저의 사용자 흐름·인증 상태·trace를 배운다.

세 문서는 목적이 다르며 고유 예제를 보존한다. 공통 도구 설치·기본 예제의 대표 문서 통합은 Claude 협의 부재로 보류했다. **본문의 정정과 예제 검증 결과를 기록했다.** 확인한 API 조건과 미확인 실행 환경을 구분하며 설명용 비율·속도 표현을 실측으로 읽지 않는다. [정리 기록](../organization-log.md)의 문서별 상태를 확인한다.
