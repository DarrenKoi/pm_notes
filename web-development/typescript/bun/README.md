# Bun 실행 예제 목차

[Bun 사용 가이드](../bun-basics.md)에서 런타임·패키지·테스트의 차이를 읽고 [Task API](./example-task-api/README.md)에서 실행·요청·기존 테스트를 확인한다.

코드 읽기 순서는 handler → 서버 연결 → 테스트다. 메모리 저장·누락된 운영 기능·JSON 입력의 한계를 실행 안내에 명시했다. Bun으로 TypeScript를 실행하는 것과 타입 검사는 다른 검증이다.
