# 웹 개발 지식 목차

이 폴더는 Python 환경·캐시, TypeScript 프론트엔드와 테스트를 함께 학습하는 독립 주제다. 각 문서의 목적·예제 조건·확인일을 함께 읽는다. [정리 기록](./organization-log.md)은 수정 근거와 미확인을 제공한다. 원본 문서의 개별 검토와 로컬·Obsidian 검증을 마쳤으며, 외부 실행과 Claude 협의 대기는 기록에 구분했다.

## 읽기 순서

1. [Python 도구·Redis](./python/README.md): 실행 환경을 준비하고 외부 상태 저장의 경계를 이해한다.
2. [TypeScript 로드맵](./typescript/README.md): 실제 노트와 미작성 계획을 구분한다.
3. [Vue 목차](./typescript/vue/README.md): 컴포넌트 계약과 상태 소유자를 배운다.
4. [테스트 목차](./testing/README.md): 순수 로직·통합·브라우저 흐름의 검증 범위를 정한다.
5. [Bun 실행 예제](./typescript/bun/README.md): 작은 HTTP handler와 로컬 테스트를 연결한다.

학습 문서는 특정 코드·운영 상태의 보증이 아니다. 원 작성일 last_updated와 이번 reviewed_on을 구분하며, 기록·실행 코드·첨부를 보존한다. 설치·버전 갱신은 문서의 명령을 무조건 실행하는 작업이 아니고 실제 환경의 lock·호환 조건을 확인하는 과정이다.
